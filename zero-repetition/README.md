# Zero repetition

فرم شناسایی سه فعالیت تکراری برای مفید آکادمی.

این پوشه نسخه نمایشی GitHub Pages است؛ فقط داده‌های نمونه در حافظه مرورگر استفاده می‌شود. ثبت واقعی پاسخ و اتصال شیت فعال نیست.

مسیر انتشار: `/zero-repetition/`

اطلاعات کارکنان، پاسخ‌های واقعی، دیتابیس، فایل تنظیمات خصوصی، رمزها و توکن‌ها نباید در این مخزن ذخیره شوند. برای جمع‌آوری واقعی، اتصال به بک‌اند خصوصی لازم است.
