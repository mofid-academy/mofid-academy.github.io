# Zero repetition

فرم شناسایی سه فعالیت تکراری برای مفید آکادمی، با ظرفیت ۳۰۰ همکار.

نسخهٔ ۳ از PostgreSQL خصوصی در پروژهٔ اختصاصی Supabase استفاده می‌کند. رابط روی GitHub Pages است و n8n فقط برای ارسال اختیاری پاسخ‌های انتخاب‌شده به Google Sheets استفاده می‌شود.

[ورود به سایت](https://mofid-academy.github.io/zero-repetition/) · [ورود مدیر](https://mofid-academy.github.io/zero-repetition/#admin)

## رفتار

- نام کاربری سازمانی مانند M.mirsheri و لینک اختصاصی امضاشده؛ مدیر با کلید خصوصی فعلی.
- حرکت بین مراحل فرم درخواست شبکه نمی‌فرستد. «ذخیره پیش‌نویس» و «ثبت نهایی» پس از تأیید پایگاه‌داده رسید می‌دهند.
- پنل مدیر: جست‌وجوی نام و نام کاربری، فیلتر واحد، پوزیشن و وضعیت پاسخ.
- اکسل واقعی از نمای فیلترشده، با راست‌به‌چپ، فونت Vazirmatn و رنگ‌های مفید؛ مستقل از شیت و n8n.
- «ارسال این نما به شیت» اختیاری است و خطای آن پاسخ اصلی را تغییر نمی‌دهد.
- پاسخ‌ها در مرورگر یا مخزن GitHub ذخیره نمی‌شوند.

## نگهداری

[بک‌اند خصوصی](backend/README.md) در منطقهٔ فرانکفورت منتشر شده است. site-config.js فقط نشانی عمومی تابع را دارد؛ رابط به zero-repetition/3 نیاز دارد. پس از تغییر هر اسکریپت، نسخهٔ کش آن را در index.html با هش همان فایل به‌روز کنید.

ثبت پاسخ‌ها، پنل مدیر و اکسل بدون n8n کار می‌کنند. اتصال اختیاری شیت در انتشار اولیه خاموش است؛ فایل خصوصی گردش‌کار آن جداگانه تحویل می‌شود.

## فایل‌های خصوصی

هیچ credential، کلید مدیریتی، کلید امضا، دادهٔ همکاران، فایل env واقعی یا گردش‌کار خصوصی n8n را در مخزن قرار ندهید. فایل‌های خصوصی جداگانه تحویل می‌شوند. رنگ‌ها، فونت وب، لوگو و ترتیب عکس‌های تأییدشده حفظ شده‌اند.
