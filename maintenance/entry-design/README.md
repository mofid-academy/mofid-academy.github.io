# طراحی صفحهٔ انتخاب و ورود مفید

صفحهٔ اصلی، دکمه‌های انتخاب آزمون و استودیو و کارت ورود استودیو از سه مرجع کاربر بازطراحی شده‌اند. فایل دوم و سوم یکسان‌اند: ظاهر Sign In Card برای فرم ورود و هاله‌های همان طرح برای پس‌زمینهٔ انتخاب به کار رفته است. حرکت تعاملی موس از الگوی Background Gradient Animation با رنگ‌های سبز، نعنایی و فیروزه‌ای مفید پیروی می‌کند. این تغییر شامل اسلایدهای ارائه یا محتوای آزمون نیست.

دکمه‌های Liquid Metal از ShaderMount و liquidMetalFragmentShader واقعی Paper Shaders نسخهٔ 0.0.82 استفاده می‌کنند. پنج ماژول لازم از commit `1923e9f536ea079e2a95d23291cbfacfd69d37f6` به ES modules مرورگر تبدیل و در همان دامنه میزبانی شده‌اند. فایل‌های LICENSE و NOTICE حفظ شده‌اند. با نبود WebGL یا خطای بارگذاری، کادر فلزی CSS باقی می‌ماند؛ لینک‌ها و دکمه‌ها به جلوه وابسته نیستند. API فعلی برای پاک‌سازی `dispose()` است. حرکت shader هنگام پنهان شدن تب یا خروج از دید متوقف می‌شود.

ظاهر ورود از طریق یک جایگزینی محدود در `MofidLogin` هنگام مونتاژ چهل فایل اصلی استودیو اعمال می‌شود. callback واقعی `onSubmit`، فراخوانی `mfApi('login', {username,password})`، کنترل نقش سوپرادمین، ذخیرهٔ نشست، خطا و شرایط غیرفعال بودن دکمه بدون تغییرند. نشان دادن رمز فقط نوع input را در state همان کامپوننت تغییر می‌دهد. گزینهٔ ورود اجتماعی، ساخت حساب عمومی یا مسیر بازیابی رمز اضافه نشده است.

`entry-ui.js` هنگام mount فرم، پس‌زمینه و جلوهٔ کارت را فعال می‌کند و هنگام unmount، listenerها، shader و پس‌زمینه را پاک می‌کند. استایل‌ها به صفحهٔ انتخاب یا کلاس موقت ورود محدودند؛ پنل ادمین پس از ورود و صفحات درس، آزمون و ارائه همان سبک قبلی را دارند. انیمیشن ارائه و فایل teaching-presentation.js تغییر نکرده‌اند.

حرکت موس با requestAnimationFrame و همگرایی آرام انجام می‌شود. pointer-events پس‌زمینه خاموش است و وارد تعامل لینک‌ها، کیبورد یا ورودی‌ها نمی‌شود. ترجیح کاهش حرکت سیستم، لمس، نمایشگر کوچک و غیرفعال بودن تب رعایت می‌شوند. جلوه‌ها هیچ مقدار فرم، توکن یا حافظهٔ حساب را نمی‌خوانند؛ تنها import ماژول‌های همان دامنه انجام می‌شود.
