اتصال ادمین به GitHub

صفحه ویرایش عمومی است، اما فقط دارنده کلید معتبر و مجوز نوشتن مخزن می‌تواند تغییرات را روی سایت منتشر کند. رمز مشترک داخل فایل قرار داده نشده است.

  1. ساخت کلید دسترسی محدود در GitHub ↗
  2. Resource owner: mofid-academy
  3. Only select repositories: فقط mofid-academy.github.io
  4. Repository permissions → Contents: Read and write

انقضای ۳۰روزه انتخاب کن. این کلید در سطح مخزن مجوز دارد، نه فقط یک فایل؛ آن را به کسی نده. به Administration یا Workflows نیاز نیست. اگر تأیید سازمان خواسته شد، مالک سازمان باید آن را تأیید کند.

کلید را در چت نفرست. این پنل آن را تنها در حافظه همین تب نگه می‌دارد و در فایل، پیش‌نویس یا مرورگر ذخیره نمی‌کند. با خروج یا بازخوانی صفحه پاک می‌شود.

در زمان برگزاری آزمون تنظیمات اتصال را تغییر نده. نسخه قبلی در تاریخچه GitHub باقی می‌ماند. تغییر فونت و تصاویر را در هر دو اندازه نمایش بررسی کن.
