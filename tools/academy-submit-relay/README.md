# واسط HTTPS ثبت پاسخ آزمون

این پوشه یک پروژهٔ آمادهٔ Netlify برای انتقال پاسخ به همان n8n فعلی است. فایل `netlify.toml` در ریشهٔ شاخه، تنظیمات ساخت و مسیرهای انتشار را مشخص می‌کند.

| مسیر واسط | مقصد |
|---|---|
| `POST /api/submit` | `https://azmoon.app.n8n.cloud/webhook/academy-submit-v5` |
| `POST /api/legacy-submit` | `https://azmoon.app.n8n.cloud/webhook/youform-exam` |
| `GET /health` | بررسی اجرای واسط؛ بدون فراخوانی n8n |

پاسخ‌ها با همان بایت‌ها و شناسهٔ ارسال منتقل می‌شوند. واسط شناسه نمی‌سازد، وضعیت موفقیت ایجاد نمی‌کند، پاسخ خطای n8n را موفق اعلام نمی‌کند و POST را خودکار تکرار نمی‌کند. بررسی هویت رسید، `accepted` و `stored` همچنان در کد موجود سامانه انجام می‌شود. هیچ کلید پاسخ یا نمره‌ای به این پروژه اضافه نشده است.

## انتشار

1. در Netlify با GitHub وارد شوید. برای آزمایش می‌توان پلن Free با سهمیهٔ محدود را انتخاب کرد.
2. از **Add new project → Import an existing project → GitHub** مخزن `mofid-academy/mofid-academy.github.io` را انتخاب کنید.
3. شاخهٔ `academy/https-submit-relay-20261025` را انتخاب کنید. تنظیمات فایل ریشه عبارت‌اند از:
   - Base directory: `tools/academy-submit-relay`
   - Build command: `npm test`
   - Publish directory: `public`
   - Functions directory: `netlify/functions`
4. پروژه را منتشر کنید. دسترسی بازدیدکننده باید **Public** باشد تا صفحهٔ ورود Netlify مانع کاربران نشود. رمز ادمین و توکن GitHub را در متغیرهای این پروژه وارد نکنید؛ این واسط فقط ارسال عمومی پاسخ را انجام می‌دهد.
5. آدرس ساخته‌شدهٔ `https://نام-پروژه.netlify.app/health` را بدون پروکسی باز کنید. خروجی سالم شامل `relay_reachable: true` و `n8n_checked: false` است. این بررسی n8n را اجرا نمی‌کند.

ساخت کد واسط به‌معنی دسترسی بدون پروکسی نیست؛ دسترسی آدرس جدید باید از شبکه‌های شرکت‌کنندگان آزمایش شود. دامنهٔ آمادهٔ Netlify نیز ممکن است در بعضی شبکه‌ها قابل دسترسی نباشد.

## اتصال به سامانه پس از آزمایش دسترسی

پس از مشخص‌شدن آدرس واقعی و تأیید دسترسی، مسیر ثبت اصلی و مسیر قدیمی باید در فایل‌های منتشرشده، نمونهٔ فرم ادمین و کنترل مسیر آزمایش ادمین به آدرس‌های متناظر این واسط متصل شوند. CSP باید دقیقاً مبدأ جدید را مجاز کند. هیچ توکن یا رمز ادمین به ارسال شرکت‌کننده افزوده نمی‌شود. این شاخه به‌تنهایی مسیر سایت اصلی را تغییر نمی‌دهد.

یک پاسخ آزمایشی باید با رسید دارای شناسه‌های هماهنگ و `accepted: true` و `stored: true` تأیید و در جدول نتایج بررسی شود. پس از گم‌شدن رسید، تلاش مجدد باید همان شناسه و همان پاسخ را بفرستد. گم‌شدن ارتباط به‌معنی ذخیره‌نشدن قطعی نیست.

## حدود این واسط

این پروژه فقط پاسخ‌های آزمون را منتقل می‌کند؛ انتقال فایل سؤال، انتشار ادمین، آرشیو و تصحیح در سرویس‌های فعلی باقی هستند. درخواست باید زیر ۵ MiB باشد؛ Netlify نیز محدودیت اندازه و مدت اجرا دارد. محدودیت انتظار upstream این واسط ۲۵ ثانیه است. خطا یا پایان انتظار همواره نتیجهٔ ثبت‌نشده/تأییدنشده برمی‌گرداند و رسید موفق نمی‌سازد.

## بررسی محلی

```sh
cd tools/academy-submit-relay
npm test
```

آزمون‌ها هیچ درخواست واقعی به n8n نمی‌فرستند و هیچ پاسخ شرکت‌کننده‌ای ثبت نمی‌کنند.
