# اعلام نحوهٔ شرکت در کلاس‌های ZERO REPEAT

فرم مستقل: https://mofid-academy.github.io/zero-repeat/attendance/

مدیریت: https://mofid-academy.github.io/zero-repeat/attendance/admin.html

نام و نام خانوادگی، نام سازمانی و انتخاب یکی از دو گزینهٔ «حضوری» یا «آنلاین» الزامی است. نام سازمانی در فرم و API بررسی می‌شود؛ نام خالی، فاصله و نشانی ایمیل پذیرفته نمی‌شود. هیچ گزینه‌ای از قبل انتخاب نشده است. `?preview=1` فرم و رسید را بدون ارسال و ذخیرهٔ اطلاعات نمایش می‌دهد.

پاسخ فقط پس از تأیید ذخیره در Supabase رسید می‌گیرد. تلاش مجدد همان شناسه و اطلاعات را ارسال می‌کند. هر ثبت مستقل است؛ نام سازمانی خوداظهاری است و پاسخ فرد دیگری را جایگزین نمی‌کند.

ظرفیت حضوری ۱۵ ثبت فعال است. API عمومی فقط تعداد و جای خالی را می‌فرستد؛ نام‌ها در دسترس عموم قرار نمی‌گیرند. ظرفیت هنگام ورود، بازگشت به صفحه و هر ۱۵ ثانیه بررسی می‌شود. پس از تکمیل ظرفیت، گزینهٔ حضوری غیرفعال می‌شود و پیام شرکت آنلاین نمایش داده می‌شود. اگر ظرفیت قابل‌بررسی نباشد، گزینهٔ آنلاین باز می‌ماند و دکمهٔ بررسی دوباره در دسترس است.

نمایش حالت تکمیل ظرفیت بدون تغییر داده‌ها: `?preview=1&capacity=full`. پارامتر `capacity` فقط در حالت پیش‌نمایش اثر دارد؛ ظرفیت واقعی همواره از سرور دریافت می‌شود.

RPC با قفل تراکنشی مشترک، ثبت و حذف را هماهنگ می‌کند. بررسی شناسهٔ قبلی پیش از ظرفیت انجام می‌شود تا تلاش مجدد پاسخ ثبت‌شده حتی پس از تکمیل ظرفیت همان رسید را بگیرد. ثبت آنلاین به ظرفیت حضوری وابسته نیست. حذف نرم ثبت حضوری، جای آن را آزاد می‌کند. `backend/capacity.sql` ارتقای نصب‌های قبلی است و پاسخ‌ها را تغییر نمی‌دهد.

پنل با حساب مدیریت فعلی ZERO REPEAT وارد می‌شود. آمار، جست‌وجوی نام، فیلتر حضوری/آنلاین، اکسل واقعی از تمام پاسخ‌های نمای انتخابی و حذف نرم با تأیید دارد. توکن مدیریت فقط در حافظهٔ همین صفحه نگهداری می‌شود. جدول و RPC مستقیماً برای مرورگر قابل‌دسترسی نیستند. پاسخ‌ها به شیت یا وبهوک نظرسنجی مدرس ارسال نمی‌شوند.

تابع مستقل `zero-repeat-attendance-api` فایل‌های `backend/index.ts` و `backend/core.mjs` را اجرا می‌کند. پیکربندی خصوصی مدیریت فقط سمت سرور از `zr_runtime_config` خوانده می‌شود. بدنهٔ تابع احراز هویت مدیریت را انجام می‌دهد و ثبت عمومی فقط اطلاعات مجاز فرم را می‌پذیرد. JWT درگاه برای این تابع مستقل خاموش است. هیچ رمز یا کلید خصوصی در این پوشه نیست.

`backend/schema.sql` فقط اشیای جدید `zr_attendance_*` را ایجاد می‌کند. فرم‌های قبلی، پرسشنامه‌ها، چالش‌ها و پاسخ‌های آن‌ها تغییر نکرده‌اند.

بررسی: `node --test zero-repeat/attendance/tests/*.test.mjs`.
